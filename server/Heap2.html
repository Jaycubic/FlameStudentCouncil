Q1: Python Maze FSM (Word Problem)
Mental Model: The Memoryless Walker
Concept: Model a maze where choices are fixed (Left-Right-Up-Down) using only F (Forward) and B (Backward).
class MazeDFA:
    def __init__(self):
        self.state = "START"
    def step(self, move):
        if self.state == "START" and move == "F":
            self.state = "CORRIDOR"
        elif self.state == "CORRIDOR":
            if move == "F": self.state = "EXIT"
            if move == "B": self.state = "START"
    def is_solved(self):
        return self.state == "EXIT"

Q3: DPDA Python Stack Evaluator
Mental Model: The Push-Pop Balance
Concept: Python script for DPDA recognizing balanced parentheses.
def is_balanced(w):
    stack = ['Z0']
    for char in w:
        if char == '(': stack.append('X')
        elif char == ')':
            if stack[-1] == 'X': stack.pop()
            else: return False
    return stack == ['Z0']
Q4: Python NFA Parallel Simulation
Mental Model: Quantum State Tracking
Concept: Simulate an NFA finding substring "11". We track a set of active states simultaneously.
def nfa_has_11(w):
    active_states = {0}
    for char in w:
        next_states = {0} # Always guess start
        if 0 in active_states and char == '1':
            next_states.add(1)
        if 1 in active_states and char == '1':
            next_states.add(2)
        active_states = next_states
    return 2 in active_states
Q5: Python TM Simulator (Unary Increment)
Mental Model: The Array Head
Concept: Simulate a TM Tape using a Python list and a head pointer.
def tm_increment(tape):
    tape = list(tape) + ['_']
    head = 0
    # Scan right
    while tape[head] == '1': head += 1
    # Replace blank with 1
    if tape[head] == '_': tape[head] = '1'
    return "".join(tape).strip('_')

Q9: Divison by 2 (Binary TM)
Mental Model: The LSB Truncator
Concept: In binary, dividing by 2 (integer division) simply means erasing the right-most bit (the Least Significant Bit). The TM scans right until it finds the end marker '!', steps left, overwrites the bit with a blank, and accepts.
Q10: Decidable vs Recognizable
Mental Model: The Infinite Loop Danger
Concept:
- Decidable: The TM will always halt (Accept or Reject) for any input.
- Recognizable: The TM will halt and Accept if the string is in the language. If it is NOT, it might Reject, or it might loop forever.

Q12: Ambiguous Grammars Proof
Mental Model: The Two-Path Conflict
Concept: A CFG is ambiguous if a string has two or more distinct leftmost derivations (or parse trees).
Example: E → E+E | E*E | a.
"a+a*a" can be parsed as (a+a)*a or a+(a*a), generating two different root trees.
Q13: Chomsky Normal Form (CNF)
Mental Model: The Binary Tree Enforcer
Concept: Convert S → aSb | ε to CNF.
1. Eliminate ε: S → aSb | ab.
2. Terminal proxies: U → a, V → b.
3. Break chains: S → U X, X → S V. S → U V.
Q14: Pumping Lemma for CFLs
Mental Model: The Dual Pump (v & y)
Concept: Prove L = {a^n b^n c^n} is not CFL. Split string s = uvwxy where |vwx| ≤ p. Because the window vwx is small, it can cover at most two symbol types (e.g., a's and b's). If we pump it, a and b increase, but c does not. The equality is broken.
Q15: Closure of CFLs
Mental Model: The Intersection Trap
Concept: CFLs are closed under Union (S → S1 | S2), but NOT closed under Intersection.
Proof: L1 = {a^n b^n c^m} is CFL. L2 = {a^m b^n c^n} is CFL.
L1 ∩ L2 = {a^n b^n c^n}, which is NOT a CFL.

Q18: Reversing DFA Arrows
Mental Model: The NFA Transformation
Concept: If you reverse all arrows of a DFA, swap Start and Accept states, is it still a DFA?
NO. It becomes an NFA. A state in the original DFA might have multiple incoming arrows for the same symbol; reversing them creates multiple outgoing arrows (non-determinism).
Q19: DFA Substring Loop Removal
Mental Model: The Pumping Cut
Concept: If a DFA has k states and reads a string of length ≥ k, it MUST repeat a state (Pigeonhole Principle). This forms a loop. If reading string '0' caused the loop, you can "pump down" (remove the 0) or "pump up" (insert '00') and the machine still ends in the exact same accept state.

PART V: ADVANCED PROOFS & UNDECIDABILITY

Q21: Prime Length Strings are Irregular
Mental Model: The Composite Pump
Concept: Prove L = {a^p | p is prime} is not regular. Assume regular, pumping length k. Pick prime p > k. String s = a^p. Pump y (length m) p+1 times. New length is p + pm = p(1+m). Since p(1+m) is composite, the pumped string is outside L. Contradiction.
Q22: The Halting Problem Word Analogy
Mental Model: The Paradox Machine
Concept: Cannot write a TM 'H' that predicts if TM 'M' halts. If H exists, we build machine 'D' that asks H what 'D' itself will do. If H says 'D halts', D intentionally loops forever. If H says 'D loops', D intentionally halts. H is broken.
Q23: Post Correspondence Problem (PCP)
Mental Model: The Domino Match
Concept: Given dominoes with top and bottom strings, can you line them up so the top sequence equals the bottom sequence?
Result: Undecidable. Used via mapping reductions to prove CFG ambiguity is also undecidable.
Q24: Mapping Reduction (A_tm → Halt_tm)
Mental Model: The Loop Trap
Concept: To prove HALT is undecidable, we reduce A_tm (Acceptance) to it. If we had a Halting solver, we could solve A_tm by wrapping the input TM in a shell that forces an infinite loop if it rejects. Then "Halting" becomes synonymous with "Accepting".
Q25: Rice's Theorem
Mental Model: The Semantic Wall
Concept: ANY non-trivial property of the language recognized by a Turing Machine is undecidable. You cannot write a program that analyzes another program's source code to determine what it computes (e.g., "does this code output 0?").

PART VI: MIXED CONCEPTUAL COMPARISONS

Q26: Why are NFA and DFA equivalent?
Mental Model: The Powerset Universe
Concept: They recognize the exact same class of languages (Regular). A DFA can simulate an NFA's "magic guessing" by keeping track of all possible states the NFA could be in simultaneously (Subset Construction). This creates at most 2^Q states.
Q27: Why are DPDA and NPDA NOT equivalent?
Mental Model: The Unknowable Center
Concept: NPDAs recognize all CFLs. DPDAs only recognize Deterministic CFLs. A DPDA cannot guess. Therefore, a language like Even Palindromes (ww^R) cannot be solved by a DPDA because it doesn't know where the middle of the string is without a center marker.
Q28: TM Enumerators
Mental Model: The Infinite Printer
Concept: An enumerator starts with a blank tape and prints out strings to a printer. A language is Turing-Recognizable if and only if some enumerator prints it. If the language is infinite, the enumerator runs forever.
Q29: Myhill-Nerode Theorem
Mental Model: Indistinguishable Futures
Concept: If two strings 'x' and 'y' lead to the exact same future outcomes for all possible appended strings 'z', they belong to the same equivalence class. This proves the minimum number of states required for a DFA is exactly the number of these equivalence classes.
Q30: P vs NP & Cook-Levin Theorem
Mental Model: Verification vs Solving
Concept:
P: Solvable quickly (polynomial time).
NP: Verifiable quickly.
Cook-Levin: Proved Boolean SAT is NP-Complete (the anchor problem). If SAT can be solved in P, then P=NP, meaning solving puzzles from scratch is mathematically as easy as checking the answer key.
